# 견적 요청 템플릿 초안

`quote`와 `manage_quotes`는 연동 선택한다. CSV 항목을 선택하고 요청 조건을 제출하며, 견적 요청과 제안은 별도 QuoteRequest 테이블에 저장한다. 특정 업종이나 컬럼명을 고정하지 않는다.

## 사용자와 관리자

- 사용자: 항목·요청 조건 작성, 전달된 견적 확인·수락·거절, 작업 시작 전 요청 취소, 진행 상태 조회.
- 관리자: 금액·통화·제안 초안 저장, 견적 전달, 처리 불가능한 요청 거절, 사용자 수락 후 진행 시작·완료 및 처리 메모.
- 금액은 음수가 아닌 정수부 12자리·소수부 2자리까지 지원한다. 문자열을 검증하여 Decimal로 저장한다. KRW/USD/EUR/JPY 중 통화를 선택한다. 환율 변환이나 자동 가격 계산은 없다.
- 요청 조건·제안·처리 메모는 각 5,000자 이내다. 사용자 화면은 본인 요청만 조회하며 미전달 초안의 금액·제안은 숨긴다.

## 상태와 검증

| 상태 | 관리자 동작 | 사용자 동작 |
| --- | --- | --- |
| 견적 대기 | 초안 저장·견적 전달·요청 거절 | 취소 |
| 견적 도착 | 없음 | 수락·거절·취소 |
| 수락 | 진행 시작 | 취소 |
| 진행 중 | 완료 | 없음 |
| 완료·요청 거절·견적 거절·취소 | 없음 | 없음 |

초안은 견적 대기 중에만 변경할 수 있다. 금액·통화·제안은 함께 저장하며 전달 이후에는 수정할 수 없다. 전달 없이 수락하거나 수락 없이 진행하는 동작을 거부한다. 행 잠금으로 상태 변경을 직렬화해 동시에 들어온 수락·거절 중 하나만 성공한다. 사용자 동작은 요청의 작성 세션을 검사한다.

CSV 항목을 삭제해도 대상 이름과 기존 요청·견적을 보존하여 처리할 수 있다. 모듈을 해제해도 데이터는 삭제하지 않고 다시 선택하면 복원한다.

## API

`/api/uploads/{id}/quote-requests/`:

- POST `{row_id, content}`: 요청 생성.
- GET: 사용자 본인 목록. 관리자 Preview는 `admin=1`로 전체 목록·초안을 조회한다. 페이지당 20개다.
- PATCH `/{quote_id}/`: `action`을 전달한다.
  - `save`: `amount` 문자열, `currency`, `proposal` 필수.
  - `send`: 저장된 초안을 전달하거나 세 견적 필드를 함께 전달한다.
  - `reject`, `start`, `complete`: 선택 `processing_note`.
  - `accept`, `decline`, `cancel`: 별도 변경 필드를 허용하지 않는다.

기존 Preview의 업로드 소유 세션 범위를 유지하며 쓰기는 CSRF를 검사한다. `admin=1`은 표시 모드이지 관리자 인증이 아니다. 외부 사용자 공개·계정별 권한은 후속이다.

## 후속 범위

전달 후 수정·재협상·견적 버전 관리·유효기간·결제·첨부·알림·전자 계약은 지원하지 않는다. AI는 구현된 범위에 적합한 CSV·추가 요청에만 추천하며 견적 작성·수락·진행에는 호출하지 않는다. 다음 후보는 설문·피드백이다.
