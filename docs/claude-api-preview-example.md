# 루트 예시 CSV의 Claude API 전송 범위

2026-09-27 기준, 저장소 루트의 예시 CSV를 로컬에서 분석한 결과다. 실제 셀 값과 원본 CSV는 이 문서에 넣지 않았다. 파일 내용이 바뀌면 아래 숫자도 달라진다.

| 항목 | 현재 예시 CSV |
| --- | ---: |
| 원본 파일 크기 | 3,461,280바이트 |
| 인코딩 | CP949 |
| 데이터 행·컬럼 | 697행·24열 |
| 브라우저 최초 표시 | 앞 20행 |
| Claude 요청용 예시 | 최대 10행 |
| 예시 행의 CSV 논리 행 번호 | 2, 3, 129, 226, 350, 351, 448, 595, 697, 698 |
| 160자 제한으로 잘린 값 | 8개 |
| 생성된 Claude 요청 본문 | 22,516바이트 |

CSV 논리 행 번호는 헤더를 1행으로 세며, 따옴표 안 줄바꿈이 있어도 레코드 하나를 한 행으로 센다. 앞 2개·중간 2개·뒤 2개를 고정하고, 나머지 4개는 파일 내용에 따라 재현 가능한 방식으로 네 구간에서 하나씩 선택한다. 같은 파일의 재분석은 같은 행을 고른다.

Claude에는 24개 컬럼의 이름·타입 후보·결측/고유값/형식 비율 등 **전체 697행에서 로컬로 계산한 통계**, 위 10개 행의 셀 값, 경고, 샘플링 정보, 시스템 지시문, 이번 CSV에 맞춘 JSON Schema를 보낸다. 문자열은 각각 최대 160자다. 원본 3.46MB 파일 전체, 나머지 687행의 셀 값, 파일 경로, 업로드 ID, API 키는 요청 본문에 넣지 않는다. 예시 행에는 실제 셀 값이 포함될 수 있으므로 호출 전 전송 범위를 확인해야 한다.

브라우저의 `전송 범위 확인`은 로컬 요청 내용을 계산하는 단계다. `Claude API 1회 호출 승인`을 누른 뒤에만 `claude-sonnet-5`에 1회 요청하며 자동 재시도는 없다. 업로드·통계 계산·목록 페이지 이동·전체 행 그래프 집계는 Claude 토큰을 쓰지 않는다. 서비스 Preview 생성에만 승인된 API 호출이 필요하다.

화면은 Sonnet 5의 [공식 기본 단가](https://platform.claude.com/docs/en/models/sonnet-5/whats-new-sonnet-5)인 입력 $2/백만 토큰, 출력 $10/백만 토큰을 기준으로 예상 비용을 표시한다. 현재 22,516바이트 요청과 최대 출력 4,000토큰의 화면 추정치는 약 **US$0.055~0.074**다. 입력 토큰은 바이트 길이로 근사하므로 이 범위는 청구액의 상한이 아니다. 실제 비용은 응답의 `usage` 토큰 수로 계산한다.

이전에 승인받아 실제로 수행한 v2 호출은 **앞 5개 데이터 행만 사용한 별도 검증**이다. `ModelCall` ID `ba21af0d-da80-406a-80cd-f9d3cf8ca945`, 입력 8,464토큰·출력 431토큰, 계산상 약 US$0.021이었다. 위 10행 요청은 로컬에서 생성하고 크기만 확인했으며, 이 요청으로 새 Claude API 호출을 실행한 기록은 없다. 이후 호출과 실패 후 재시도에는 각각 새 승인이 필요하다.
