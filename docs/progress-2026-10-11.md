# Sheet2Service 작업 정리 — 2026-10-11

## 이용 과정

CSV 업로드 → 생성 확인 모달 → `/select?upload=<UUID>` → CSV 미리보기 → 열별 분석 → 서비스 기능 선택 → 프리뷰 생성 → 대시보드·사용자·관리자 화면.

CSV 클릭·드래그 업로드와 자동 인코딩을 지원한다. XLSX는 지원 예정이다. 생성 모달의 취소는 파일 선택과 화면 상태를 초기화하며 서버에 저장된 원본을 삭제하는 기능은 아니다. 사용자 버튼 동작으로 모델을 요청하고 자동 재시도는 하지 않는다.

## 템플릿

| 기능 | 사용자 | 관리자 |
| --- | --- | --- |
| 목록 | 목록·상세 조회 | 데이터·필드·선택지 관리 |
| 문의 | 문의 작성·내 문의 | 답변·처리 상태 관리 |
| 신청·승인 | 신청·취소·내역 | 승인·거절·처리 |
| 즉시 접수 | 접수·취소·내역 | 접수 관리·처리 |
| 예약 | 일정·정원 확인·예약·취소 | 일정·정원·마감·예약 내역 |
| 공지 | 게시 공지 조회 | 작성·수정·게시·게시 해제 |
| 대여·반납 | 대여 신청·취소·내역 | 재고·승인·대여·반납 |
| 견적 | 조건 요청·수락·거절·취소 | 초안·전달·진행·완료 |

각 템플릿의 API와 제약은 `*-template.md`, 조합 계약은 `service-features.md`, 후보 목록은 `template-registry.md`에 기록했다. 특정 체육시설 데이터에 한정하지 않고 검증된 설정으로 실행한다.

## 추천과 선택

- AI가 선별한 후보만 표시하며 전체 템플릿 목록은 노출하지 않는다. 제목은 데이터의 주제와 작업을 반영한다.
- 구현된 추천은 기본 선택한다. 신청·승인과 즉시 접수는 택 1이며 추천 순서의 첫 항목만 기본 선택한다. 저장된 선택은 우선 복원한다.
- 사용자·관리자 쌍은 함께 선택·해제한다. 연결 항목을 상단 같은 행에 배치하고 직선으로 연결한다. 독립 항목은 아래에 빈칸 없이 배치한다.
- 목록 조회·관리자 데이터 관리·대시보드는 독립 선택이다. 역할별 선택 수는 선택 가능한 최대 기준 `N/M개 선택`으로 표시한다.
- 추가 기능 입력 폼은 항상 표시한다. 전송하면 내부 사전 조회 후 모델 요청 1회로 연결한다. 결과는 입력 박스 바깥 아래 기존 안내 박스로 표시한다.
- 직접 입력은 등록된 목록 기준으로 지원·미구현·미지원 여부를 판별한다. 대상은 현재 사용자·관리자다.

## 사용자 화면 정리

- Sheet2Service 이름으로 통일했다. 메인은 설명·사진과 업로드 카드의 중앙 배치이며 사진은 왼쪽 정렬이다.
- 재사용 가능한 푸터와 제목 아이콘을 추가했다. 푸터는 브랜드·메일 아이콘·Contact·이메일을 링크 없는 텍스트로 표시한다.
- 생성 모달은 넉넉한 여백, 점선 파일 박스, 파일 옆 로딩을 사용한다. 업로드 박스에는 선택 파일명을 추가하지 않는다. 비용·전송 정보 등 개발용 UI 설명은 제거했다.
- select는 단계 오른쪽 정렬, 활성 단계 밝은 색상, 파일명 클릭 다운로드를 제공한다. 이전·다음·프리뷰 생성 버튼은 내용 박스 바깥에 둔다. 호출 정보는 제거했다.
- CSV 표는 컬럼명 전체 표시, 데이터 길이 기반 너비, 긴 값 말줄임, 한 행씩 펼침, 행 번호 고정, 옅은 컬럼 구분선을 사용한다. 펼침 화살표는 없다.
- 인코딩은 미리보기 제목 옆, 행·열 수는 오른쪽, 바이트 경고는 표 아래에 표시한다.
- 분석 표는 번호 열과 값 개수 단위를 제공하고 전체 정보를 표시한다. 비율 기반 너비로 불필요한 가로 스크롤을 줄였다.
- 서비스 화면 상단 오른쪽 메뉴는 대시보드 → 사용자 → 관리자 순서다. 기능 선택으로 돌아가기 버튼은 제거했다.
- `frontend/src/service.css`로 템플릿 버튼·hover·카드·입력창·표·상태·페이지 이동 스타일을 통일했다. 기능 탭에는 작은 아이콘을 사용하고 개발용 설명을 줄였다. 기존 처리 기능은 유지한다.

## 데이터 목록 검색·필터

- 사용자 데이터 목록을 카드 대신 간결한 행 목록으로 바꿨다. 최대 3개의 요약 필드와 상세 보기를 제공한다.
- 일반적인 ID·UUID·식별번호 컬럼은 사용자 표시에서 제외한다. 원본/API 데이터를 삭제하거나 접근 권한을 변경한 것은 아니다.
- 사용자 목록과 관리자 데이터 관리에 검색·컬럼 값 필터·초기화를 추가했다.
- `GET /api/uploads/{id}/managed-rows/`는 `q`, `filter_column`(1부터 시작), `filter_value`를 지원한다.
- 검색은 전체 데이터의 부분 문자열 검색, 필터는 정확한 값 일치다. 두 조건을 함께 적용한 뒤 결과 개수와 20개 단위 페이지를 계산한다. 페이지 이동 시 조건을 유지한다.
- 업로드 소유 세션 범위를 유지하며 검색·필터는 모델을 호출하지 않는다.

## 모델 및 검증

- 구조화 출력 스키마 중복을 줄이고 서버 검증을 유지했다. 출력 잘림을 줄이기 위해 기본 최대 토큰은 4,000에서 8,000으로 조정했다.
- 실제 사용자 키로 Claude를 호출하는 테스트는 하지 않았다. API 키와 업로드 데이터는 커밋에 포함하지 않는다.
- 프론트 빌드, 기능 선택·프리뷰 설정·공개 컬럼 검증과 데이터 API 검증을 수행했다. API 검증에는 페이지 밖 검색, 필터 조합, 특수문자, 빈 결과, 잘못된 조건, 세션 격리가 포함된다.
- 최종 회귀 검사 결과는 `handoff.md`에 기록한다. 브라우저 검증은 사용자 담당이다.

## 남은 작업

- 문의·예약·대여·견적 등 목록의 검색·상태 필터.
- 직접 입력에서 대시보드 대상 지원.
- 사용자 표시 컬럼을 이름 규칙 대신 설정으로 선택하는 구조 검토.
- 읽지 못한 문자 위치 검토·수정 기능. 현재는 원본 보존과 대체 문자 표시만 지원한다.
- 약관·개인정보 보호정책 문서/페이지. 현재는 안내 문구만 있다.
- 외부 사용자 인증·관리자 권한. 현재 프리뷰는 업로드 소유 브라우저 세션에서 동작한다.
- 템플릿별 사용자 UI 확인과 정밀 피드백 반영.
