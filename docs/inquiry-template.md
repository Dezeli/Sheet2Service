# 문의 접수 템플릿 v1

CSV 분야에 관계없이 사용할 수 있는 고정 템플릿이다. 문의 데이터는 CSV 관리 행과 별도 DB 모델 `Inquiry`에 저장한다. 제출·조회·답변·집계는 일반 코드로 실행하며 Claude를 호출하지 않는다.

## 설정 계약

- 유저 enum: `inquiry`
- 관리자 enum: `reply_inquiries`
- 두 템플릿은 함께 선택한다.
- `subjectColumn: 0`: 일반 문의. CSV 항목 선택 없이 제목·내용을 입력한다.
- `subjectColumn: 1..N`: 해당 컬럼을 항목 제목으로 사용한다. 관련 항목 선택은 선택 사항이다. 관리자 설정은 유저의 항목 컬럼과 동일하게 저장한다.
- 단계 설명은 일반 코드가 실제 기능에서 생성한다. 모델이 출력한 예약·결제 등의 설명을 실행 가능한 단계로 표시하지 않는다.

현재 입력은 제목(1~120자)·내용(1~5,000자)·선택적 관련 항목으로 고정한다. 임의 입력 필드, 파일 첨부, 연락처, 알림은 이 계약에 포함하지 않는다.

## 처리 계약

상태 enum은 `received`(접수), `in_progress`(처리 중), `resolved`(완료)이다. 관리자가 답변과 상태를 저장한다. 완료 상태에는 공백이 아닌 답변이 필요하다. 완료한 문의도 답변을 수정하거나 처리 중으로 돌릴 수 있다.

관련 CSV 행을 삭제해도 문의 제목·내용·항목명 스냅샷은 보존한다. 목록은 20건씩 조회한다. 사용자 화면은 같은 세션에서 작성한 문의를 조회하고, 관리자 화면은 해당 업로드의 문의를 조회한다. 새로고침 버튼으로 답변과 집계를 갱신한다.

## 선택과 확인

기존 분석 결과에도 기본 `문의 접수`·`문의 답변·처리` 후보를 추가한다. 이 후보 선택에는 추가 Claude 호출이 필요하지 않다. 새 Claude 요청의 enum에도 두 템플릿이 등록된다.

플로우 선택 화면에서 두 문의 후보를 선택해 프리뷰를 생성한 뒤 User에서 제출하고 Admin의 문의 관리에서 답변한다. User와 Dashboard에서 새로고침하면 답변과 상태 집계가 반영된다.

현재 서비스 접근은 기존 업로드 소유 세션에 한정한다. 별도 브라우저 사용자 접근·관리자 인증은 후속 작업이며, 외부 사용자에게 공개하는 문의 서비스는 아직 아니다.
