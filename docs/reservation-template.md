# 일정·정원 예약 템플릿 초안

CSV는 예약 대상을 정의하는 목록이다. 예약 일정과 예약 내역은 별도 DB 테이블에 저장한다. CSV 날짜나 시설별 규칙을 고정하지 않아 교육·상담·행사 등에도 같은 구성을 적용한다.

## 지원 기능

- 사용자 `reservation`: 항목별 미래 예약 시간·잔여 정원 조회, 1자리 예약, 내 예약 확인·시작 전 취소.
- 관리자 `manage_reservations`: CSV 항목 선택, 시작·종료 시간과 정원으로 일정 생성, 정원 변경·접수 마감, 예약 내역 조회.
- 문의·목록·신청과 함께 선택할 수 있으며 예약의 유저/관리자 기능은 연동 선택된다. AI가 추천했거나 사용자 직접 요청이 지원됨으로 판단됐을 때 후보로 표시한다. 전체 목록을 자동 표시하지 않는다.

관리자 화면의 시간 입력은 브라우저의 현재 시간대이며 API에는 시간대가 포함된 ISO 날짜로 전송한다. 예약은 즉시 확정이다. 신청·승인의 승인 처리와는 별도 기능이다.

## 검증

- 시작은 미래이며 종료가 시작보다 늦어야 한다. 정원은 1~10,000 사이 정수다.
- 같은 CSV 항목에 시작/종료가 겹치는 일정을 만들 수 없다. 앞 일정 종료와 다음 일정 시작이 같은 인접 일정은 허용한다. 접수 마감은 기존 일정을 삭제하거나 예약을 취소하지 않는다.
- 예약 시 업로드 행 잠금으로 검증·저장을 직렬화한다. 정원 초과, 같은 세션의 겹치는 시간 예약, 닫힌/시작된/대상이 삭제된 일정의 예약을 거부한다.
- 취소는 시작 전 본인 예약만 가능하고 자리가 즉시 반환된다. 같은 슬롯에 활성 예약을 중복 저장하지 못하도록 DB 제약도 둔다.
- 정원을 기존 활성 예약 수보다 줄일 수 없다. 예약 시작·종료 시간은 생성 후 바꾸지 않는다. 항목이 삭제돼도 예약 대상 이름과 내역은 보존한다.

## API

`/api/uploads/{id}/` 아래에서 사용한다. 소유 세션과 선택된 예약 모듈을 검사하며 쓰기는 CSRF 검증을 적용한다.

| 경로 | 동작 |
| --- | --- |
| `reservation-slots/` | GET 일정 조회, POST 일정 생성 |
| `reservation-slots/{id}/` | PATCH 정원·접수 마감 |
| `reservations/` | GET 예약 조회, POST 예약 |
| `reservations/{id}/` | PATCH `{cancelled: true}` 취소 |

목록은 페이지당 20개다. 사용자 일정은 `available=1`, 본인 예약은 `mine=1`로 조회한다.

## 후속 범위

기존 Preview처럼 업로드 소유 브라우저 세션 안에서 사용자·관리자 화면을 시연한다. 외부 사용자 서비스 공개, 계정·역할 인증, 실제 사람 단위 중복 검사는 아직 없다. 현재 중복 판단의 기준은 브라우저 세션이다.

반복 일정, 일정 변경·삭제, 예약 승인, 다인원 예약, 대기 순번, 결제·알림은 지원하지 않는다. 다음 독립 템플릿은 공지, 대여·반납, 견적 요청 순서로 진행하고 대기·담당자 배정은 기존 기능의 확장으로 검토한다.
